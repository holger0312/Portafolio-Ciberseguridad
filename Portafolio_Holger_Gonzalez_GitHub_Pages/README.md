# HG // CYBERSPACE

Portafolio web personal de **Holger Raúl González Villarreal**, estudiante de Licenciatura en Ciberseguridad (UTP).

## Contenido

- `index.html`: sitio web en español y accesible, con navegación por secciones.
- `styles.css`: identidad visual original, diseño adaptable a escritorio/móvil y tema claro/oscuro.
- `script.js`: filtros de proyectos, detalles, terminal informativa, menú, copia de correo y otras interacciones.
- `assets/favicon.svg`: icono vectorial original.
- `assets/CV_Holger_Raul_Gonzalez_Villarreal.pdf`: currículum listo para descargar.

No requiere npm, dependencias, registro, APIs ni conexión para funcionar una vez descargado.

## Probarlo en tu computadora

Descomprime el ZIP y abre `index.html` en Chrome, Firefox, Edge o Safari. Los enlaces internos y el botón de descargar el CV funcionan con rutas relativas.

## Publicarlo gratis en GitHub Pages

1. Entra a GitHub e inicia sesión con **tu propia cuenta**.
2. Crea un repositorio público, por ejemplo `mi-portafolio`.
3. Sube **todo el contenido de la carpeta** (el archivo `index.html` debe estar en la raíz del repositorio, junto con `styles.css` y `script.js`).
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
6. GitHub mostrará el enlace de tu sitio en esa misma sección cuando termine de publicarlo.

Si prefieres una dirección como `tuusuario.github.io`, nombra el repositorio exactamente `tuusuario.github.io` (sustituyendo `tuusuario` por tu usuario real).

## Personalización

- **Información:** edita el contenido de `index.html`.
- **Colores:** edita las variables de `:root` en `styles.css`.
- **Detalles de proyectos y comandos de la terminal:** modifica `projectDetails` y `terminalResponses` en `script.js`.
- **CV:** sustituye `assets/CV_Holger_Raul_Gonzalez_Villarreal.pdf` si lo actualizas (conserva el nombre del archivo o cambia el enlace en `index.html`).
- **Contacto:** actualmente usa los datos presentes en el CV; cambia ambos enlaces `mailto:` y `tel:` si se modifican.

### Aclaraciones

- La terminal es una **simulación informativa local**. No ejecuta comandos del sistema ni recopila información.
- Los diagramas técnicos de las tarjetas son ilustraciones de conceptos, no capturas de proyectos operativos.
- No se han inventado cuentas de GitHub/LinkedIn, métricas de logros, certificados, resultados de seguridad ni enlaces a repositorios.
- Los proyectos y el perfil reflejan los contenidos del CV que proporcionaste.
